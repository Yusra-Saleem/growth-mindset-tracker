# Growth Mindset Tracker

> Habit reflection, personal development milestones, and growth mindset goals application.

## Overview

An interactive web application built with Streamlit that guides users through daily goal setting, mindset reflections, and resilience challenges to foster continuous personal growth.

## Key Features

- Daily growth mindset reflection prompts and journaling module
- Goal milestone checklist with completion progress metrics
- Inspirational quote generator and resilience challenge library
- Session state management with data persistence

## Architecture and Technology Stack

- **Core Technologies:** Python, Streamlit, Pandas, Data Visualization

## Getting Started

### Prerequisites

Ensure you have the required runtime environment installed for this repository:
- Node.js (v18+) for JavaScript/TypeScript projects
- Python (3.10+) for Python services and agent workflows

### Installation

Clone the repository to your local machine:

```bash
git clone https://github.com/Yusra-Saleem/growth-mindset-tracker.git
cd growth-mindset-tracker
```

Install dependencies:

```bash
# For Node / Next.js projects
npm install

# For Python projects
pip install -r requirements.txt
```

### Running Locally

```bash
# Start local development server
npm run dev

# Or for Python entry points
python main.py
```
